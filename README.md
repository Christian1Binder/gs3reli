# Religions-Lernwelt – Klasse 3 (Bayern)

Interaktive, touchfreundliche Lern-App für das iPad zu **Sankt Martin**, **Reformationstag** und **Halloween**, orientiert an den bereitgestellten Unterrichtsblättern.

## Inhalte
- 15 Lernkarten (5 je Thema)
- 15 Quizfragen mit unmittelbarer Rückmeldung
- Zuordnungsspiel mit 10 Paaren
- Reihenfolge-Spiel mit 7 Ereignissen aus Martins Leben
- Lernfortschritt im lokalen Browser-Speicher

## Benutzung
Die Datei `index.html` direkt im Browser öffnen oder über GitHub Pages veröffentlichen. Kein Build, keine Abhängigkeiten, keine Anmeldung. Die App benötigt keine externen Dienste.

## GitHub Pages
Unter **Settings → Pages → Build and deployment → Source: Deploy from a branch → main / (root) → Save** aktivieren. Anschließend ist die App unter `https://christian1binder.github.io/gs3reli/` erreichbar (sobald Pages erfolgreich veröffentlicht wurde).

## Hinweise
Die aktuelle Version verwendet Emojis als Bildsymbole, noch keine eigens gezeichneten Illustrationen. Sie ist ein erster testbarer Stand. Die Aussagen folgen der Darstellung auf den Arbeitsblättern; einzelne Überlieferungen (etwa Thesenanschlag, Gänsestall und Jack) sind als solche zu verstehen. Fortschritt wird nur auf dem jeweiligen Gerät gespeichert.
